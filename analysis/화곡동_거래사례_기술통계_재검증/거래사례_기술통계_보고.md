통계 방법: 표본표준편차(n-1), 사분위수는 선형보간(엑셀 QUARTILE.INC와 동일), 이상치는 Tukey 1.5×IQR 울타리. 분석 모델 지식 시점: 2026년 6월까지(수치는 모두 파일 값에서 계산).

## 1단계 자료점검
- 토지 행 33건, 결측 0, 완전중복 0(지번+거래시점+금액 기준). 동일 지번·동일일자 1건(지번 1043, 2025-09-19)은 면적·금액이 달라 별개 거래로 판단.
- 기준시점(2026-05-29) 이후 7건(행 70,76,82,88,112,124,130) 제외 → 표본 26건.
- 단위: 단가 원/㎡, 면적 ㎡. 단가는 `토지총액 ÷ 전용면적(J열)`로 계산된 값(수식 확인).
- 행178: 전체면적 175.2 < 전용면적 317.3(면적 이상). 단가는 317.3 기준(5,672,864). 전체면적 기준이면 10,273,973(울타리 초과). 면적 확인 필요 → 본 분석은 파일 단가 그대로 포함, 제외 시 민감도 병기.

## 한계점
- 시점수정, 개별요인(면적·형상·접면 등) 비교 자료 없음 → 사례 단가는 미보정 원자료(2024-11~2026-05 혼재).
- 단가는 건물 배분(재조달원가·잔가율 가정)을 뺀 토지 배분액이라 배분 가정의 영향을 받음.
- 표본 26건, 변동계수 27%로 산포 큼. 공시지가 격차율은 본건 1개 공시지가 기준(사례별 공시지가 자료 없음).
- 행178 면적 이상 미확정.

## 최종 단가 제시 가능 여부
