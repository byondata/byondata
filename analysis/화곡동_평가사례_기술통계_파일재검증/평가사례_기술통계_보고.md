# 화곡동 평가사례 기술통계 분석 (파일 재검증)

- **출처**: 3.서울_강서구_화곡동.xlsx — `평가사례` 시트(단가 L열, 개별지가 M열, 격차율 N열, 시점수정치 O열, 기준시점 K열 및 각 사례 하단 원자료행 S~AM열), `본건` 시트 A1(기준시점 2026-05-29)·F6(공시지가 3,431,000원/㎡)·E6(면적 241㎡)
- **자료 작성 시점**: 엑셀 사례 기준시점 2024-06-10 ~ 2026-09-21 (파일 내 최신 연도 2026). 분석 방법(사분위수 선형보간, Tukey 1.5×IQR 울타리, t분포 신뢰구간)은 일반 통계 지식(분석자의 학습자료, 2026-06 이전)에 의존하며 외부 웹 출처는 조회하지 않음.
- **범위**: 위 파일만 사용. 외부 수치 없음. 단가·공시지가 단위: 원/㎡.

## 2단계 기술통계 (n=58, 단가 원/㎡)
- 평균 = Σx/n = **8,174,397** / 중앙값(29·30번째 평균) = **8,115,000**
- 표본표준편차 s = √[Σ(x−x̄)²/(n−1)] = **1,766,779** (CV 21.6%)
- 사분위수(선형보간, Excel QUARTILE.INC 동일): Q1 = **6,985,000**, Q3 = **9,292,500**, IQR = Q3−Q1 = **2,307,500**
- 최소 4,600,000 / 최대 14,100,000

시각화: `2_기술통계_분포.png`

## 3단계 분포·이상치
- 평균−중앙값 = 59,397원(중앙값의 +0.7%), 표본왜도 0.67 → 거의 대칭, 우측 꼬리가 약간 긺.
- 울타리: 하한 Q1−1.5×IQR = 3,523,750 / 상한 Q3+1.5×IQR = 12,753,750
- **이상치 1건**: 기호 C, 14,100,000원/㎡ (555.7㎡, 상한 초과). 하한 이탈 0건. (제외 후 재산정 시 12,500,000이 다시 경계를 넘으나 단일 판정 원칙으로 추가 제외하지 않음)

시각화: `3_이상치_IQR.png`

## 4단계 공시지가 격차율 (단가÷개별지가, n=58)
- 평균 2.163배 / 중앙값 2.161배 / s 0.426 / Q1 1.887, Q3 2.412 / 울타리 1.100~3.198
- 이상치 2건: 3.817(기호 C), 3.222(기호 35). 모두 상한 초과.
- 본건 공시지가 3,431,000 × 격차율 중앙값 2.161 = **7,413,907원/㎡** (교차검증용)

시각화: `4_격차율.png`

## 5단계 단가 도출
- 이상치(기호 C) 제외 n=57: 평균 **8,070,439**, s 1,593,498, 표준오차 s/√n = 211,064, 95% 신뢰구간(t=2.003) **7,647,627 ~ 8,493,251**
- **제시 단가(통계 기반 참고단가): 8,070,000원/㎡** (이상치 제외 평균, 만 단위 절사)
- 교차검증: 격차율 방식 7,413,907은 제시 단가보다 8.1% 낮음. 본건 공시지가(3,431,000)가 표본 중앙 공시지가(3,698,000)보다 낮은 점이 원인. 제시 단가의 격차율 = 8,070,000÷3,431,000 = 2.352배로 사례 사분위(1.887~2.412) 안.

## 분석의 한계
1. **자료 부족: 시점수정치** (71건 결측). 사례 기준시점이 2024-06~2026-05에 걸쳐 있으나 시점수정 미적용. (기준시점-단가 순위상관 −0.02로 뚜렷한 추세는 없음)
2. **자료 부족: 개별요인 비교치(도로·형상·지세·면적 격차율, 본건 대비 보정률)**. 본건(241㎡, 단독, 세로(가), 정방형)과 상업용·각지·대규모 사례가 혼재.
3. 평가목적이 담보·시가참고·법원경매·조세 등 혼재하며 거래가격이 아닌 평가액이라는 한계가 있음.
4. 같은 필지 중복 평가(826번지 5건, 1071번지 2건 등)로 표본 독립성이 약함.
5. 열 밀림으로 이용상황 등 범주 변수는 요약행 기준 분석 불가(원자료행으로 재확인 필요).

## 최종 단가를 확정 제시할 수 없는 사유
시점수정치와 개별요인 보정 자료가 없어 감정평가 실무상 확정 단가가 아닌 **표본 통계 기반 참고단가**로만 제시함.

## 결론 (3줄)
1. 평가사례 72건 중 기준시점 이후 14건을 제외한 58건 기준 평균 8,174,397·중앙값 8,115,000원/㎡로 거의 대칭 분포, 이상치는 1건(14,100,000).
2. 격차율은 평균 2.16배(단가가 공시지가의 약 2.2배)이며 본건 공시지가 환산 시 7,413,907원/㎡.
3. 이상치 제외 평균 기준 참고단가 8,070,000원/㎡(95% CI 7.65~8.49백만원). 시점수정·개별요인 자료 부족으로 확정은 불가.
